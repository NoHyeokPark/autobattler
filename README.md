# 덱빌딩 오토배틀러 프로토타입 v0.2

설계 문서 v0.1 기반의 프로토타입. 핵심 루프(상점 → 지도에서 노드 선택 → 매칭 → 전투 → 보상)와 PvP 기록 매칭, 밸런스 시뮬레이터, 웹 버전과 기획자용 에디터까지 포함한다.

## v0.2 변경 사항 (규칙 버전 2 — v1 저장·기록과는 호환되지 않음)

| 항목 | 내용 |
| --- | --- |
| 보상 선택지 = 같은 등급 | 장신구 보상은 등급을 먼저 하나 뽑고(전투·엘리트: 일차 확률표, 보스: 일차별 고정 등급) 그 등급의 서로 다른 장신구 `run.rewardChoices`개를 보여 준다 (그 등급에 모자라면 있는 만큼). 이벤트 떠돌이 몬스터도 같은 방식으로 3마리 중 하나를 고르거나, 그 등급 몬스터 값만큼 골드로 받는다 |
| 장신구 중첩 | 같은 장신구가 상점·보상에 다시 나오고, 가진 개수만큼 효과가 무한히 중첩된다 (상점 레벨·수입 보너스 포함). 배낭은 `x2`처럼 묶어서 표시. 한 번의 진열·선택지 안에서만 겹치지 않는다 |
| 몬스터 성장 | Lv2가 되면 (그 몬스터 전용 성장 + 공용 성장) 중 3개를 제시하고 하나를 고른다. Lv3은 새로 고르지 않고 합성에 쓴 Lv2 3장의 성장을 모두 가진다 (반복 가능 성장은 중첩, 반복 불가 성장이 겹치면 하나만). 고르는 레벨은 `balance.unit.growthChoiceLevels` |
| 전투 밖 효과 | 새 효과 3종: **영구 강화**(공격력·체력·주문력·행동 간격·추가발동, 이번 전투에 바로 적용 + 유닛에 남음), **골드 획득**, **무작위 장신구 획득**(등급 지정). 플레이어 쪽만 전투 후 런에 반영되고 **승패와 무관** (연패하며 스택 쌓기 가능). 골드·장신구는 전투당 상한(`balance.battleGains`, 기본 8골드·2개)으로 추가발동 폭주를 막는다. 상대(기록)의 영구 강화는 기록 당시 값으로 남아 있어 PvP에서도 쌓인 유닛을 만난다 |
| 봇 전략 | 성장형·경제형 추가 (시드 봇은 전투가 없어 기존 3전략만). 모든 봇은 남은 목숨이 2 이하면 모아 둔 골드를 리롤에 몰아 쓰는 "올인"을 한다. 이게 없을 때 이자형은 4패 상태에서도 평균 73골드를 들고 14%만 쓰고 탈락했다 (올인 후 평균 승 2.2~2.7 → 3.5~3.7) |
| 장신구 분류 | **지속**(가지고 있는 동안 효과, 개수만큼 중첩) / **일회성**(조건이 맞는 순간 발동하고 사라짐, 대상이 없으면 배낭에서 대기). 효과로 자동 분류되고 카드·배낭·에디터에 표시 (일회성 카드는 점선 테두리) |
| 혼돈의 주사위 (영웅, 일회성) | 보드의 몬스터 하나를 무작위로 골라 한 단계 높은 등급의 무작위 몬스터로 변이. 레벨·고른 성장(원래 몬스터 전용 성장 포함)·영구 강화는 유지, 외형은 새 몬스터의 기본 모습. 신화 몬스터는 기원 몬스터가 될 수 있다. 봇 500판 기준 런의 27.6%에서 한 번 이상 등장 |
| 혼돈의 동전 (희귀, 일회성) | 혼돈의 주사위와 같은 변이지만 보드의 일반·고급 몬스터만 대상 (장신구의 `passive.transmuteMaxGrade` = 변이 대상 등급 상한, 에디터에서 설정). 변이 장신구가 여럿이면 대상 범위가 좁은 것부터 쓴다 |
| 몬스터 전직 | 일부 몬스터에만 넣는 Lv3 각성 (잉어킹 → 갸라도스형). 몬스터의 `promotions` 목록: 최고 레벨(Lv3)이 되면 **반드시** 전직하고, 길이 하나면 바로, 여럿이면 일반 성장 선택 크기의 모달에서 고른다 (Lv2 성장 선택이 남아 있으면 그것부터). 전직은 성장처럼 능력치·능력·태그를 더하고(가진 성장은 유지, % 는 다른 성장의 % 와 합산) 이름이 전직 이름으로 바뀐다. 전직할 몬스터는 Lv3 외형 선택 대신 전직 모습(`art/monsters/<id>.lv3.<전직 id>.png`)을 쓴다. 연출은 리더보다 가볍게: 몬스터 대사 자리의 작은 알림("슬라임 → 갸라도스" + 전직 대사, 없으면 최고 레벨 대사). 상세 보기에 "Lv3 전직" 미리보기. 변이(혼돈의 주사위·동전)로 다른 몬스터가 되면 원래 몬스터의 전직은 떨어지고, 새 몬스터에 전직이 있으면 새로 전직. 봇은 전직을 무작위로 고른다. 에디터: 몬스터 편집의 "전직" 칸 (전직 대사 포함) |
| 상점 등장 여부 | 몬스터·장신구의 `shop: false` = 상점(장신구는 상점·보상·장신구 획득 효과의 무작위 뽑기 포함)에 나오지 않음. 혼돈의 주사위 같은 변이나 이후 이벤트로만 얻는 유닛용. 변이는 상점 여부와 상관없이 위 등급 몬스터로 바꾼다. 확률표의 "몬스터 없는 등급 무시"도 상점에 나오는 몬스터 기준. 에디터 등급 옆 체크 |
| 거울 정령 (기원, 상점 미등장) | 같은 칸의 상대가 행동할 때마다(추가발동 하나하나) 그 "행동할 때" 효과를 내 능력치·내 편 기준으로 따라 한다 (새 효과 `mimic` = 따라 하기, 반응 트리거에서만). 영구 강화·골드·장신구 획득도 따라 해서 내 편이 얻는다 (영구 강화는 내 편 대상에게). 따라 한 효과는 다시 따라 하지 않는다. 신화 몬스터가 혼돈의 주사위로 변이할 때 나온다 |
| 기원 연출 | 기원 카드는 검은 바탕에 옅은 보랏빛 광채와 천천히 지나가는 빛줄기 (움직임 줄이기 설정이면 꺼짐). 기원 몬스터·장신구를 얻는 순간(상점 구매, 보상 선택, 전투 중 장신구 획득, 혼돈의 주사위 변이) 몬스터 대사 자리에 검은 "기원 등급 획득" 알림 (몬스터는 처음 구매 대사 또는 상세 대사, 장신구는 설명). 리더 전직보다 가볍게 |
| 지휘자 (기원, 상점에 나옴) | 전투 시작에 주변 8칸(리더 포함)에서 **태그가 있고 자기 주변 8칸에 태그가 겹치는 유닛이 없는** 유닛을 바로 행동시킨다 (추가발동 포함, 1열 시작 기절 무시, 원래 쿨다운은 그대로 = 보너스 행동). 행동시킨 수 n만큼 전투 후 골드 +n, 3명마다 고급 장신구 1개, 8명(완벽한 공연)이면 황금 지휘봉. 태그를 엇갈려 놓는 배치 퍼즐 덱이고, 8명은 9명 배치가 필요해 후반에만 가능. **통솔력 1**: 보드에 있는 동안 배치 인원 +1 (자기 자리를 스스로 채움 = 몬스터 `deploy`, 에디터 "통솔력"). 지휘자와 벤치 유닛을 맞바꿔 인원이 넘치는 이동은 막고, 봇도 한 명 더 올린다. 새 효과 `conduct`(지휘) = 대상·같은 태그 조건·1명당 골드·몇 명마다 장신구·완벽한 공연 장신구를 에디터에서 설정 |
| 런 지도 (노드) | 슬레이 더 스파이어식 지도: 런을 시작할 때 시드로 14일 × 4갈래 지도를 만들고(길 6개를 엇갈리지 않게 그음), 매일 **어제 노드와 이어진 노드** 중 하나를 고른다. 노드 = 종류 + 환경(일반·체력 증가·공격 증가). 종류: 일반(장신구 보상) · 엘리트(일차+1 상대, 이기면 보상 추가) · 보스(3·6·9·12일차의 엘리트가 보스로 나옴, 같은 날 엘리트와 함께 나오지 않음) · **안전 날**(`map.safeDays`, 기본 6일차)로 갈 때는 어느 노드에서든 엘리트·보스가 아닌 선택지가 하나 이상 · **모닥불**(4·7·10·13일차 선택지, 전날 보스와 이어진 칸이 `map.campfireBossWeight`배 잘 뽑힘(기본 8 ≈ 보스의 75%가 모닥불과 이어짐), 장신구 대신 라이프 +1, 승패 무관·그날 져도 탈락 전에 반영) · **이벤트 ?**(장신구 대신 골드 / 떠돌이 몬스터(일차 확률표로 등급 하나, 그 등급 몬스터 3마리 중 하나를 고르거나 그 등급 몬스터 값만큼 골드, 다음 날 벤치, 가득 차면 골드) / 리더 이벤트 성장 중 하나) · 최종 보스(14일차). 연장 중에는 엘리트·보스가 일반 전투 (9승 이후에도 그대로). **라이프** = 패배 한도 + 모닥불, 0이면 탈락. 14일차 시작 때 남은 라이프(마지막 전투용 1개 제외) 하나당 30골드, 라이프가 남은 채 끝나면 "기한 종료". 웹: 상점 화면 "지도" 버튼(누르면 고르기), 오른쪽은 이어진 다음 노드만. 터미널 `map`, 에이전트 `info map`. 수치는 에디터 "수치 → 런 지도·이벤트 노드", 리더 이벤트 성장(기본: 흡혈귀의 피 = 행동 시 공격력 50% + 주문력 50% 회복)은 "공용 성장" 탭 |
| 황금 지휘봉 (기원, 상점·보상 미등장) | 일회성: 다음 날 상점 단계가 시작될 때 지휘자를 뺀 보드의 몬스터 전부를 한 단계 높은 등급의 무작위 몬스터로 (레벨·성장·영구 강화 유지) → 배치와 멤버를 새로 맞추는 "새 주제". 장신구 옵션 `transmuteAll` + 뺄 몬스터 `transmuteExcept`. 하루 시작에 일어난 일은 화면 알림으로 보여 준다 |
| 체력 소모 (자해) | 새 효과 `hpCost`: 아군 팀 체력을 현재 체력 % + 고정값만큼 깎고(실드 무시, 1 아래로는 안 내려가 스스로 쓰러지지 않음) 안쪽 효과를 발동. 안쪽 효과는 비례 출처 "소모한 체력"(`paidHp`)을 쓸 수 있다. 줄어든 체력으로 "아군 체력 N% 이하" 능력과 잃은 체력 비례 효과가 같이 굴러간다. 누구의 피해로도 기록하지 않음 |
| 보스·엘리트전 조건 | 능력(트리거)마다 "엘리트전만"·"보스전만"(`onlyIn`, 보스 = 최종 보스 포함)을 체크하면 그 노드의 전투에서만 그 능력이 있다. 설명 앞에 "보스전 · " 표시. 테스트 탭에 노드 선택 추가 |
| 태그 시너지 | TFT 특성처럼 보드에 같은 태그가 정해진 수 이상이면 그 단계의 능력이 생기는 보조 수단. 같은 몬스터는 여러 장이어도 1명, 리더 태그도 센다. 도달한 가장 높은 단계 하나만 적용. 능력은 장신구처럼 기준 칸 = 중앙인 시스템 효과이고, 낸 피해·회복은 분석에 "<시너지> 태그". 상점 보드 위에 시너지 막대(단계·지금 수, 마우스를 올리면 단계별 효과), 에디터 "시너지" 탭에서 태그마다 단계(필요한 수·능력·설명) 편집. 모드 데이터 `synergies` |
| 내일 수입 | 상점 위의 수입 표시는 내일 받을 수입 (지금 골드를 남기면): 기본 + 이자(지금 골드 기준) + 장신구, "nG 더 남기면 이자 +1" |
| 기절 | 기절 중에는 남은 대기 시간(쿨다운)이 줄지 않아 기절한 만큼 다음 행동이 그대로 늦어진다 (쿨다운이 긴 유닛에도 효과). 대기 시간이 이미 0인 유닛도 기절 중에는 행동하지 않고 풀리는 tick에 행동한다 (같은 tick에 먼저 행동한 유닛이 건 기절 포함). 기절 중에는 반응 트리거도 발동하지 않는다 |
| 성장 촉진 장신구 | 1회용, 장신구 등급 이하 몬스터 대상. 진화의 돌 계열(일반·고급·희귀·영웅): 얻으면 보드·벤치의 Lv1 유닛 하나를 무작위로 Lv2로 (배치로 대상을 고를 수 없게 벤치까지 포함. 대상이 없으면 생길 때까지 보관, 상점 밖에서 얻으면 다음 상점 단계 시작에 발동). 각성의 두루마리 계열: 다음에 사는 몬스터가 Lv2로 들어온다. 둘 다 성장 선택이 뜨고, 여러 개면 낮은 등급부터 쓴다 |
| 성장형·경제형 콘텐츠 | 애벌레·수련생·고대 거북·현자(영구 강화), 행상 고블린·금광 드워프(골드), 보물 사냥꾼·장신구 "보물 지도 조각"(장신구), 공용 성장 "자라나는 힘", 기사 성장 "백전노장"(리더도 쌓임) |
| 영구 강화 병합 | 같은 유닛에 쌓이는 영구 강화는 합산, 합성 때는 **합산하지 않고 계열별 최고값**만 남는다 (행동 간격은 가장 많이 줄인 값). Lv1에 강화를 모아 한 번에 키우는 것을 막기 위함. 성장은 합성 때 모두 합쳐진다 |
| 성장 선택지 확장 | 리더·몬스터 공통: 능력치(고정·%·주문력), **새 능력 추가**, **기존 능력 제거**(둘을 함께 쓰면 교체), **태그 추가·제거** |
| 엘리트 보상 | "엘리트 보너스: 확률표 앞당김" 수치 삭제. 대신 확률표를 앞당기는 장신구 추가(탐험가의 지도 +2, 기존 망원경 +1, 중첩 가능) |
| 상점 | 6칸 |
| 일차별 체력 | 양측 최대 체력에 일차별 배율 적용 (`balance.scaling.hpPctByDay`, 100% → 14일차 300%). `npm run sim -- days`로 맞춰서 전투 평균 길이가 전 일차 19~23초로 유지되고, 14일차 3초 내 종료가 11.6% → 0%가 됨 |
| 능력 대상 | 대상 = **진영(아군/상대) + 범위(전체 / 방향 지정 / 같은 행 / 같은 열)**. 방향은 기준 칸 주변 8방향+기준 칸의 아무 조합. 상대 쪽 기준 칸은 같은 번호의 칸(대칭 위치). 장신구는 칸이 없으므로 보드 중앙(2행 2열)이 기준 칸. 예) "아래 아군 공격력 +40%", "대칭 위치의 위·오른쪽 상대 공격력 -20%" |
| 주문력 | 유닛 능력치 `주문력` 추가 (레벨 배율·성장으로 함께 오름). 팀 상태 중첩 = 주문력 x% (반올림). 피해·회복·실드에도 주문력 %를 섞을 수 있다. 장신구처럼 유닛이 없는 효과는 고정값 |

예전 형식 모드 파일(대상 `scope`, 상태 `stacks`)은 불러올 때 새 형식으로 자동 변환된다.

## 웹 버전

**게임 탭**: 리더 선택 → 상점 단계(보드 3x3·벤치·상점·노드) → 전투 재생 → 분석 → 보상. 유닛은 끌어다 놓아 옮기고(클릭은 정보 보기만), 오른쪽 상자로 끌어다 놓으면 판매한다. 상점 잠금은 다음 날 도착하거나 리롤하면 풀린다. 단계마다 `saves/web-run.json`에 자동 저장된다. 리더 선택 화면의 "봇 기록 생성"으로 PvP 기록 풀(`saves/records.json`)을 만든다.

**카드**: 일러스트가 없으면 등급색 프레임 안에 흰 배경 + 검은 글씨. 일러스트는 프로젝트의 `art/` 폴더에 파일로 두며, 레벨과 **외형 변화 성장**(이브이 진화처럼 성격이 크게 바뀌는 성장)마다 다른 이미지를 쓸 수 있다. 파일 이름 규칙은 [art/README.md](art/README.md). 에디터의 "일러스트" 칸에서 올리면 최대 512px webp로 줄여서 저장한다. Lv3 합성 때 재료들의 외형이 다르면 어느 외형으로 진화할지 고르는 창이 뜬다. 설명(`desc`)을 비우면 능력 데이터에서 설명을 자동으로 만든다.

**에디터 탭** (기획자·모드 도구):

| 탭 | 내용 |
| --- | --- |
| 몬스터 / 리더 / 장신구 | 카드 목록 + 폼 + 실시간 카드 미리보기(Lv1~3). 능력은 "트리거(전투 시작/행동 시/N초) → 효과" 편집기로 만든다. 대상은 진영 + 3x3 방향 선택판. 몬스터·리더는 성장 선택지 편집(능력치, 새 능력, 기존 능력 제거 체크, 태그 추가·제거). 성장의 "외형 변화" 표시. 레벨·외형별 일러스트 칸(파일 이름·대체 이미지 표시, 업로드·삭제). 새로 만들기·복제·삭제, JSON 직접 편집 |
| 공용 성장 | 모든 몬스터가 레벨업 때 공유하는 성장 선택지 |
| 수치 | `balance.ts`의 모든 수치 (상점 확률표는 표로 편집) |
| 테스트 | 두 팀을 직접 짜서 전투 재생·분석 / 봇 팀 대전으로 카드 승률·전투 길이 통계. "리더를 더미로"를 켜면 팀은 원래 리더로 만들고 전투에서만 리더를 행동 없는 더미(체력 지정)로 바꾼다. 장신구별 승률(가진 팀 기준)도 나온다. 리더 없는 팀도 짤 수 있다 |
| 밸런스 테스트 | 테스트 파티를 저장해 두고 그 일차의 봇 팀 N개와 양 진영으로 붙여 승률(기준 50%)·평균 시간·칸별 피해 몫·상대 리더별 승률을 잰다. 리더 없는 파티 + 상대 리더 빼기로 몬스터만 비교, 교체 비교로 한 칸에 후보 몬스터를 하나씩 넣어 승률 순위. 측정 기록이 남아 수치 수정 전후를 비교. 상대를 **플레이 기록 풀**(PvP 매칭과 같은 기록, 일차 ±범위)로 바꿀 수 있고, **리그전**으로 테스트 파티끼리(원하면 기록 묶음도) 붙여 상성표·리그 승률을 본다. 리더 설정 "양쪽 리더 빼기 / 비교"로 파티 구성의 힘(리더 제외 승률)과 리더의 몫(차이)을 나눠 본다. "영구 성장 누적"을 켜면 시작 일차부터 기준 일차 전날까지 하루 한 전투씩(그날 봇 5팀 평균) 얻는 영구 강화를 칸별로 쌓고 잰다. 파티 편집기에서 칸별 영구 강화를 직접 넣을 수 있다 (테스트 탭도). **장신구 비교**: 선택한 파티 또는 체크한 파티 전체에 전투 능력이 있는 장신구를 하나씩 더해(또는 그것 하나만) 승률 변화·같은 등급 대비·파티별 변화를 본다. 골드를 적지 않은 파티는 상대들의 보유 골드 중앙값을 쓴다 ("내 골드만큼" 효과용). `saves/balance-tests.json`에 모드별 저장 |
| 모드 | **이름별 모드**(`mods/library/모드이름.json`: 적용·편집·복제·내보내기·삭제, 새 모드는 기본 데이터에서 시작, "초안 저장"은 적용 없이 보관. 삭제는 `mods/backup/library/`로 옮김), 모드 이름, **새 기본 항목 가져오기**(모드 저장 뒤 코드에 추가된 몬스터·리더·장신구·공용 성장, 그리고 기존 리더·몬스터에 새로 생긴 성장을 골라 넣기. 탭에 개수 표시), 태그 추가·삭제, JSON 내보내기·가져오기, 기본값 초기화 |

편집은 초안에만 반영되고 **"변경 사항 적용"** 을 눌러야 게임에 들어간다. 오류(중복 id, 정수가 아닌 수치, 일반 몬스터 없음 등)가 있으면 적용되지 않는다. 적용한 값은 `mods/editor.json`에 저장되고, 터미널 시뮬레이터가 따로 내보내기 없이 그대로 쓴다 (`npm run sim -- league`). 다른 사람에게 줄 때는 "모드 → JSON 내보내기".

### 상점 단계 명령어

```
buy N        상점 N번 구매 (같은 몬스터 3장이면 자동 합성)
sell X       판매. X = 보드 1~9 / 벤치 b1~b6
mv X Y       이동·교체. 예) mv b1 5

```

## AI 에이전트 플레이 모드

LLM 에이전트가 게임을 플레이하기 위한 모드. 짧은 관찰 텍스트를 읽고 한 줄 명령 묶음을 보낸다.
규칙을 새로 구현하지 않고 웹·터미널 버전과 같은 함수(`src/game/shop.ts`·`run.ts`·`day.ts`)를 그대로 부르므로,
**같은 시드 + 같은 행동 + 같은 기록 풀이면 원본 게임과 결과가 같다** (`test/agent.test.ts`: 한 판 전체를 게임 함수 직접 호출과 매 단계 비교, 행동 기록으로 다시 실행해 같은 상태 확인).

| 방법 | 사용 |
|---|---|
| 명령줄 | `npm run agent -- rules` · `new [리더] [--seed N]` · `state` · `do "buy S2; move B1 5; node 1; ready"` · `info 대상` · `log` |
| MCP 서버 | 프로젝트의 `.mcp.json`(서버 이름 `autobattler`). Claude Code에서 이 폴더를 열면 연결을 묻는다. 도구: `rules`, `new_game`, `get_state`, `act`, `info`, `action_log`. 다른 MCP 클라이언트: `node --disable-warning=ExperimentalWarning src/agent/mcp.ts` (stdio) |

- **명령**: 상점 `buy S2` · `sell 5`/`sell B1` · `move B1 5` · `reroll` · `lock [on|off]` · `node N` · `ready` · `stop` / 선택 `pick N` · `reroll` · `gold` · `extend yes|no` / 정보 `info S1|5|B2|이름|monsters|trinkets|leaders|synergies|slots`. `;`로 여러 개를 한 번에 보내고, 실패하거나 전투가 끝나면 거기서 멈춘다 (결과를 보고 다시 정하게). **합성 미리 보기**: 사면 합성되는 상점 몬스터 아래에 그때 나올 성장·전직 선택지를 미리 보여 준다 (상태를 복사해 실제로 사 본 결과라 시드상 똑같음) → `buy S2; pick 강인함; move B1 5`처럼 한 번에. `pick`은 이름으로도 고를 수 있다(같은 묶음에서 다른 합성·리롤로 번호가 바뀌어도 안전, 없는 이름이면 멈춤). 리더 성장 등 선택 단계에서도 상점이 보여 `pick 2; buy S1; ...`로 하루를 한 번에 보낼 수 있다.
- **런은 끝까지**: 진행 중인 런이 있으면 `new_game`은 거절된다. `abandon: true`(명령줄 `--abandon`)로 포기하면 포기로 기록된다. 모든 런의 결과(우승·탈락·포기, 승패, 전직)는 `saves/agent/history.json`에 쌓이고 `new_game`·`action_log`에 요약이 나온다.
- **판단 메모**: `act`의 `note`(명령줄 `--note "..."`)에 이유를 적으면 그 행동 위치에 저장되어 `action_log`에 💭로 함께 나온다 (플레이 돌아보기용).
- **저장**: `saves/agent/session.json` (런 상태 + 시드 + 행동 기록, 새 런을 시작하면 이전 것은 `saves/agent/runs/`로). 리더 기록은 `saves/agent/profile.json`에 따로. 실패한 명령도 기록한다 (게임 함수가 실패하면서도 유닛 번호를 쓰는 등 상태를 조금 바꿀 수 있어서).
- **상대**: 공용 PvP 기록 풀(`saves/records.json`)을 웹 게임과 같은 조건으로 읽기만 한다. 에이전트의 기록을 풀에 넣으려면 `--share-records` (MCP는 환경 변수 `AB_AGENT_SHARE_RECORDS=1`).
- **환경 변수**: `AB_AGENT_DIR`(세션 폴더, 에이전트 여럿을 따로 돌릴 때), `AB_AGENT_MOD`(모드 이름·파일), `AB_AGENT_NO_MOD=1`(기본 데이터). 런 도중 모드가 바뀌면 상태에 경고가 붙는다.

시작 프롬프트 예 (Claude Sonnet 등에 MCP를 연결한 뒤):

> autobattler MCP 도구로 덱빌딩 오토배틀러를 한 판 플레이해 줘. 먼저 rules를 읽고 new_game으로 시작해.
> 매일 상점에서 무엇을 사고 어디에 놓을지 이유를 act의 note에 짧게 적고, act에는 하루치 명령을 묶어서 보내.
> 판이 끝나면 잘된 점·실패한 점과 다음 판에 쓸 전략을 정리해 줘.

## 구조

```
src/                  게임 로직 (터미널·웹 공용, 화면을 모름)
  config/balance.ts   모든 수치(확률표, 가격, 칸 효과, 서든데스, 안전 한도…). 코드와 분리
  data/               몬스터 28종(전용 성장 포함), 리더 3명, 장신구 19종, 공용 몬스터 성장 — 트리거→효과 데이터
    growth.ts         성장 적용 계산 (엔진·카드 공용) / targets.ts  대상 지정 도우미·예전 형식 변환
    registry.ts       모드 적용 (데이터 객체를 제자리에서 교체)
    validate.ts       모드 검증 / describe.ts  자동 설명 생성
  core/               결정적 난수(mulberry32), 정수 연산(안전 한도 클램프, BigInt 폴백)
  battle/engine.ts    결정적 tick 전투 엔진. 이벤트 로그만 출력
  game/               런 상태 전이, 상점·합성, 노드, 매칭(폴백), 봇, 저장, 리더 기록
  ui/                 터미널 화면: 상점, 전투 재생(배속), 전투 분석
  sim/                밸런스 시뮬레이터 (pairs.ts·league.ts·partyTest.ts는 웹 에디터도 사용)
  agent/              AI 에이전트 플레이 모드 (agent.ts 관찰·명령, session.ts 저장, cli.ts 명령줄, mcp.ts MCP 서버)
web/                  React 웹 프론트엔드
  components/         카드, 3x3 보드, 모달
  game/               게임 화면 (상점 단계, 전투 재생, 분석, 선택 창)
  editor/             에디터 (유닛·장신구·수치·테스트·모드)
test/                 node:test 테스트
```

- **시너지 3종을 하나의 구조로**: 모든 능력은 `트리거(battleStart / act / timer) → 효과[]`이고, 태그 버프는 `tag` 필터, 위치 효과는 `adjacent`·`mirror`·`sameRow` 필터로 표현한다. 새 시너지는 대부분 데이터만 추가하면 된다.
- **엔진**: 10 tick = 1초. 정렬 키는 (시스템 우선, 플레이어 우선, 슬롯 번호, 등록 순번). 같은 입력이면 항상 같은 결과이고, 기록 스냅샷(팀·배치·일차·환경·규칙 버전)만으로 전투가 재현된다.

| 서든데스 | 60초부터 매초 20 × 1.5ⁿ, 실드 무시 |
| 상태 효과 | 독: 매초 중첩만큼 피해(실드 무시), 화상: 독과 같지만 매초 중첩 -1, 재생: 매초 중첩만큼 회복, 강화: 공격 피해 +중첩, 가시: 상대 유닛의 피해 효과를 받을 때마다 공격한 쪽에 중첩만큼 피해(추가발동도 1회씩). 설명은 에디터 수치 탭에 설정값 기준으로 표시 |
| 전투 분석: 상태 피해 귀속 | 팀 상태(독·화상·괴사·가시·재생)가 낸 피해·회복을 그 상태를 건 유닛에게 중첩 비율대로 나눠 기록한다 (감쇠·정화·소모로 줄면 기여도 같은 비율로 줄어듦). 분석 표의 유닛 피해·회복에 포함되고 "(상태 N)" "(재생 N)"으로 몫을 표시. 장신구는 진영별 한 줄. 전투 상세 보기의 실시간 기록도 같은 기준 |
| 전투 분석: 버프 피해 귀속 | 다른 아군에게 건 전투 한정 버프의 몫은 버프를 건 쪽 기록: 강화 상태가 공격마다 더한 피해는 강화를 건 쪽들에게 중첩 비율대로, 공격력·주문력 +N·+%로 올려 준 몫은 그 능력치에 비례한 피해·회복·실드(계수·"내 공격력만큼" 비례 포함)를 같은 비율로 나눈다. 받은 유닛 기록에서는 빠지고 "(버프 N)"으로 표시. 영구 강화·자기 버프·칸 효과는 본인 몫. 가속·추가발동 버프는 귀속하지 않음 |
| 전직 선택 화면 (Lv3 갈림길) | 리더 선택과 함께 서사를 전하는 순간이라 전체 화면으로 연출. 길마다 세로 일러스트 패널(전직 형태 일러스트, 없으면 지금 모습의 실루엣과 "?")에 이름·종류·전직 대사. 누르면 펼쳐져 전직 이야기(lore)·효과·보드 태그 일치 수와 "이 길을 걷는다" 버튼이 나오고, 확정하면 고른 길만 남는 연출 뒤 전직 연출로 이어진다. ← → / Enter / Esc. 에디터 리더 화면의 "전직 이야기" 칸과 "전직 선택 화면 미리보기"(저장 전 초안 그대로) |
| 반응 트리거 | 발동 시점 "반응": 지정한 유닛(아군/상대, 칸·행·열·태그·종류 필터. 유닛은 자신 칸 기준·자신 제외, 장신구는 중앙 기준)이 행동할 때마다 발동. 추가발동도 1번씩 센다. "N번 행동마다", "전투당 최대 N회" 설정. 반응으로 낸 효과는 행동이 아니라 다른 반응·행동 횟수에 들어가지 않고(무한 연쇄 없음), 기절 중에는 반응하지 않음(세지도 않음). 지켜볼 유닛은 전투 시작 때 정해진다. 재생 화면에서 반응한 유닛도 움찔 |
| 상대 체력 트리거 | 발동 시점 "상대 체력 N% 이하가 될 때 (1회)": 상대 팀 체력이 처음 그 아래로 내려간 순간 (아군 체력 트리거와 같은 처리) |
| 대사 | **리더**: 상황별 대사를 플레이어일 때 / 상대 리더로 나왔을 때 따로 (상대 칸을 비우면 플레이어 대사). 전투 시작 3초·팀 체력 첫 30% 이하 3초 말풍선, 결과 배너에 양쪽 리더의 승리·패배 대사, 전직 선택 카드·전직 연출에 전직 대사. 전직 성장에도 같은 칸이 있어서 쓴 칸만 바뀐다. **몬스터**: 상세 보기 대사, 이번 런에서 처음 샀을 때·Lv3이 됐을 때 상점 아래 카드 말풍선. **능력 말풍선**: 트리거마다 "발동할 때" 대사, 상태 소모는 "소모 성공 시" 필살기 대사 → 그 유닛 카드 위 2초 말풍선 + 전투 기록 |
| 리더 소개 화면 | 리더 선택에서 카드를 누르면 그 자리에서 커지듯 소개 화면이 열린다: 큰 일러스트, 이름·칭호·대사·소개(서사), 시작 능력치, 기본 능력, Lv3 전직 미리보기, 성장 목록, 내 기록. ← → 로 넘기고 Enter로 시작. 칭호·대사·소개는 에디터 리더 탭에서 쓰고 "소개 화면 미리보기"로 확인 |
| 비례 ("내 X만큼") | 피해·회복·실드·팀 상태·공격력+·주문력+·가속+ 효과에 비례 항을 여러 개 붙일 수 있다: 출처 값 × % (100% = 1당 1). 출처: 자신 공격력·주문력·체력·가속·추가발동·행동 횟수, 내 골드(전투 시점), 아군/상대 팀 상태 중첩(독·화상·재생·강화·가시), 아군 실드, 아군/상대 잃은 체력, 아군/상대 유닛 수(태그·리더/몬스터로 거름). 설명에는 아는 값은 계산해서, 전투 중에만 아는 값은 계수로("20+") 보이고, 전투 상세 보기에서는 지금 값으로 다 계산된다 |
| 정화·해주 | 정화 = 아군에게 걸린 해로운 상태(독·화상), 해주 = 상대에게 걸린 이로운 상태(재생·강화·가시)를 상태마다 중첩 × % (내림) + 고정값만큼 줄인다. 범위: 전부 / 가장 많이 쌓인 하나. 비율이라 많이 쌓은 덱일수록 많이 깎인다 (50% 초과는 경고). 범주는 상태 설정의 "해로움"으로 정해진다. 예시 장신구: 정화의 소금, 해주의 바늘 |
| 상태 상호작용 | 팀 상태 설정의 "줄일 상태 + 계수 %": 이 상태가 터질 때마다 같은 팀의 다른 상태를 (중첩 × 계수%)만큼 줄인다. 기본: 화상 → 가시 50%. 수치 탭에서 조절·추가 |
| 희망 / 상태 소모 | 희망 = 주기 효과가 없는 이로운 팀 상태(자원). 쌓기는 "팀 상태 부여"로 한다. "상태 소모" 효과: 지정한 상태를 N만큼 (또는 N 이상이면 전부) 써서 안쪽 효과들을 발동하고, 모자라면 아무 일도 없다. 안쪽 효과는 비례 출처 "소모한 중첩"으로 쓴 만큼 강해진다. 상대에게 걸린 상태를 소모(터뜨리기)할 수도 있다. 이로운 상태라 해주에 깎인다. 태그 전용이 아닌 범용 부품 |
| 관통 피해 | 피해 효과의 "관통"을 켜면 실드를 무시한다 (실드 덱 견제) |
| 괴사 | 해로운 팀 상태. 주기마다 피해를 주고, 들어간 피해만큼 최대 체력도 줄인다 (이번 전투 동안, 회복으로 못 되돌림 → 회복 덱 견제). 실드에는 막힌다 (독과 반대). 체력바 오른쪽 어두운 칸 = 잃은 최대 체력. 시간 초과 판정은 원래 최대 체력 기준. 상태 설정의 "최대 체력을 깎음"으로 다른 상태에도 적용 가능 |
| 체력 N% 이하 트리거 | 유닛·장신구 능력의 시점 "아군 체력 N% 이하가 될 때 (1회)": 처음 그 아래로 내려간 순간 한 번 발동 (비상 실드·회복 같은 카드용) |
| 대상: 리더/몬스터 | 대상 조건에 "유닛 종류"(리더만·몬스터만)가 있다. 예) "아군 리더 공격력 +20%" |
| 가속 | 행동 속도 스탯. 행동 간격 = 기본 × 100 / (100 + 가속). **합산**이라 +50 두 번 = +100 = 간격 절반 (곱하기처럼 0으로 수렴하지 않음, 가속 1점의 가치가 항상 같다). 음수는 감속 (최대 5배 느려짐). 칸 효과(1열 ×0.7, 3열 ×1.2, 3행 ×1.5)는 최종값에 따로 곱한다. 예전 "행동 간격 %" 데이터는 불러올 때 한 번 적용한 결과가 같은 가속으로 바뀐다 (-15% → +18, +40% → -29) |
| 능력 설명 수치 | 롤 툴팁처럼 능력치에 비례하는 수치는 지금 능력치로 계산한 값을 굵게, 계수를 괄호로 보여 준다: "16(⚔100%) 피해", "3(✦10%) 독". 숫자 색 = 비례하는 능력치(공격력 주황·주문력 보라·체력 빨강, 섞이면 검정). 전투 중에는 버프된 공격력·주문력으로 다시 계산. 계산식은 전투 엔진과 같다 (테스트로 확인). 설명을 비워 둔 유닛의 카드, 상세 보기, 리더 소개에 적용 |
| 카드·상세 보기 | 일러스트가 있으면 그림 중심 카드: 소(보드·전투) = 그림 전체 + 이름·능력치 띠, 중(상점·선택) = 그림 48% + 요약 2줄, 대 = 그림 50% + 요약. 일러스트가 없으면 흰 바탕 글자 카드. 능력치는 아이콘(체력·공격·주문·행동 간격·추가발동). 능력 전체·성장(xN)·영구 강화는 **상세 보기**에서: 상점은 유닛 선택 또는 상점 카드에 마우스를 올리면, 전투는 카드를 누르면 같은 화면이 나온다. 그림 규격은 art/README.md |
| Lv3 보유 시 상점 제외 | 최고 레벨(Lv3)로 가진 몬스터(보드·벤치)는 상점에 더 나오지 않는다 (한 유닛 도배 방지). 그 등급에 남은 몬스터가 없으면 가까운 등급에서 뽑는다. 수치 탭 `shop.hideMaxLevelOwned`로 끄고 켬 |
| 성장 다시 뽑기 | 증강 리롤처럼 성장 선택마다 1회 무료로 선택지를 다시 뽑는다 (리더 레벨업·몬스터 Lv2 성장, 전직 제외). 지금 보이는 것과 다른 성장이 우선으로 나온다. 웹은 "선택지 다시 뽑기" 버튼, 터미널은 `r`. 횟수는 수치 탭 `leader.growthRerolls`·`unit.growthRerolls` |
| 성장 등장 레벨 | 리더 성장·몬스터 전용 성장에 등장 레벨 구간(`minLevel`·`maxLevel`)을 줄 수 있다. 그 레벨에 도달할 때만 선택지에 나온다 (에디터 성장 편집의 "등장 레벨 구간") |
| 공용 성장 등장 조건 | 공용 몬스터 성장은 레벨 구간 대신 **등장 등급 구간**(`minGrade`·`maxGrade`)과 **태그 조건**(`forTags` + `tagMode`: 체크한 태그 중 하나라도 있는 몬스터에게만 / 하나라도 있으면 제외)으로 어떤 몬스터에게 나올지 정한다. 태그는 지금 태그(성장으로 바뀐 태그 포함) 기준 |
| 등급 7단계 | 일반(회색)·고급(초록)·희귀(파랑)·영웅(보라)·전설(노랑)·신화(빨강)·기원(테두리 없이 검은 바탕에 흰 글씨). 등급 **숫자는 예전 그대로** 두고 이름이 한 칸씩 내려갔다 (희귀 2 → 고급, 에픽 3 → 희귀, 전설 4 → 영웅, 신화 5 → 전설, 기원 6 → 신화). 7번 기원은 새로 생긴 빈 등급으로 상점에 나오지 않고(확률 0) 보스 보상 등급을 7로 정하면 나온다. 예전 모드(version 2)는 불러올 때 확률표·가격에 기원 칸을 붙이고, 설명 글의 등급 표기("희귀 이하", "무작위 희귀 장신구" 등)만 새 이름으로 바꾼다 ("전설의 마법소녀" 같은 이름은 그대로). 예전 기원(상점 미등장, 0G)이던 장신구는 신화가 되어 가격이 생기고, 신화가 뽑히면 상점·보상에도 나올 수 있다 |
| 상점 레벨 · 빈 등급 | 화면의 "상점 레벨" = 실제로 쓰는 확률표 줄 (일차 + 상점 레벨 장신구, 표 끝을 넘으면 마지막 줄). 마우스를 올리면 그 줄의 등급별 확률. 확률표에 확률이 있어도 몬스터가 없는 등급의 칸은 무시하고 나머지 비율대로 뽑는다 (예전: 아래 등급으로 내려가서 기원 칸 1%가 신화 몬스터로 나왔음). 전투·엘리트 보상의 장신구 등급은 기원 칸을 뺀다 (기원 장신구는 보스 보상 전용). 검사 탭이 "몬스터 없는 등급에 확률"을 경고 |
| 플레이 데이터 정리 | 에디터 "플레이 데이터" 탭: PvP 기록 풀(`saves/records.json`)을 분류별로 보여 주고 지운다 (이 모드에서 쓰는 기록 · 모드 표시 없는 예전 기록 · 예전 규칙 버전 · 재현할 수 없는 기록 · 다른 모드별). 리더 기록 초기화, 진행 중인 런 삭제도 여기서. 지우기 전 파일은 개발 서버가 `saves/backup/`에 이름별 최근 10개까지 백업 |
| 리더 전직 | 리더의 일반 성장(`growth`)과 따로 관리하는 전직 목록(`promotions`): 태그와 콘셉트가 바뀌는 변신 3개 + 태그를 유지하고 원래 콘셉트를 키우는 본질 강화 1개(검성·대강령술사·대성녀). 리더 Lv3(7일차, `leader.promotionLevels`)에 일반 성장 대신 전직만 제시(본질 강화 맨 앞 고정 자리), 리더당 하나. 예전 모드의 일반 성장에 섞인 변신은 불러올 때 전직으로 옮겨진다. 원래 리더의 특성은 남는다 (기사 → 죽음의 기사: 흡혈 / 성녀 → 저주받은 망령: 회복을 잃고 언데드 공격 보조). 선택 화면에 보드 태그 수 표시, 봇은 가장 많이 모인 태그 쪽으로 변신. `npm run sim -- league`에 변신별 성적 |

## 시뮬레이터 첫 결과 (v0.1 기준, seed 1 — v0.2에서 다시 측정 필요)

수치를 조정하기 전 상태의 관찰이다.

- **동률 우대**: 플레이어 측 승률 50.5%, 진영만 바꿨을 때 승패가 뒤집히는 매치 1.4%. 단, 회복·실드 유닛은 먼저 행동하면 가득 찬 HP에 회복을 낭비할 수 있어서 플레이어 우선이 항상 이득은 아니다.
- **전투 길이(8일차)**: 중앙값 일반 17초 / 체력 증가 19초 / 공격 증가 15초. 서든데스 발동 0.5~3.3%.
- **시작 즉시 종료**: 일반 환경 0.6%, 공격 증가 환경 1.3%가 t=0에 끝남 (3열 한방 유닛). 목표인 "사실상 0"보다 높다.
- **추가발동**: 팀 합계 10~19의 승률이 88.5%로 높다. 다른 빌드의 스케일링 조정이 필요하다.
- **골드 전략**: 이자형 봇의 평균 승수가 1.6으로 크게 낮다. 봇 휴리스틱이 단순한 탓도 있어서 결론을 내리기 전에 봇부터 다듬어야 한다.
- **엘리트·보스**: 엘리트 승률 약 26%, 보스 17~27%. 일차+1 상대가 꽤 강하다.
- **칸 효과**: 3·4·6칸이 어떤 몬스터에게도 최고 칸이 되지 않았다. 1·2·7·8칸에 쏠린다.
